# 🏰 Virtual Excursions Platform

Платформа виртуальных экскурсий по достопримечательностям Минска и Минской области.  
Fullstack-приложение с интерактивной картой, фильтрами, построением маршрутов и рекомендациями похожих объектов.

---

## 📋 Описание проекта

Приложение позволяет:
- 🗺️ Просматривать достопримечательности на интерактивной карте (OpenStreetMap + Leaflet)
- 🔍 Фильтровать объекты по категории, району, названию и радиусу от пользователя
- 📍 Использовать геолокацию для поиска объектов рядом
- 🚗 Строить реальные маршруты через OSRM (расстояние + время в пути)
- 🔗 Открывать маршрут в Яндекс Картах
- 🎯 Находить похожие объекты и достопримечательности рядом

---

## 🛠 Технологический стек

### Backend
- **Python 3.11+**
- **FastAPI** — REST API
- **SQLAlchemy** — ORM
- **PostgreSQL** — база данных
- **Docker** — контейнеризация БД
- **OSRM** — построение маршрутов

### Frontend
- **React 18 + TypeScript**
- **Vite** — сборщик
- **Leaflet + react-leaflet** — карта
- **Axios** — HTTP-клиент

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd virtual-excursions-platform
```

---

### 2. Запуск базы данных (PostgreSQL)

База данных поднимается через Docker. Файл `docker-compose.yml` находится в **корне проекта**.

```bash
docker compose up -d
```

Проверка:
```bash
docker ps
```
Должен появиться контейнер со статусом `Up` (например, `virtual-excursions-db`).

---

### 3. Настройка Backend

Откройте **первый терминал**:

```bash
cd backend

# Создаём виртуальное окружение
python -m venv .venv

# Активируем его
# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# Windows (CMD):
.\.venv\Scripts\activate.bat
# macOS / Linux:
source .venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Заполняем базу тестовыми данными
python -m app.seed

# Запускаем сервер
uvicorn app.main:app --reload
```

✅ Backend доступен: **http://127.0.0.1:8000**  
📘 Swagger-документация: **http://127.0.0.1:8000/docs**

> ⚠️ Если PowerShell ругается на выполнение скриптов:  
> `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`

---

### 4. Настройка Frontend

Откройте **второй терминал** (не закрывая первый):

```bash
cd frontend

# Устанавливаем зависимости
npm install

# Запускаем dev-сервер
npm run dev
```

✅ Frontend доступен: **http://localhost:5173**

> Vite настроен так, что все запросы к `/api` автоматически проксируются на backend (`http://127.0.0.1:8000`).

## 🎮 Как пользоваться

1. Откройте в браузере: **http://localhost:5173**
2. Слева — панель фильтров и список объектов
3. По центру — карта с маркерами
4. Справа — карточка выбранного объекта

### Демо-сценарии

| № | Действие | Результат |
|---|----------|-----------|
| 1 | Открыть сайт | На карте отображаются все достопримечательности |
| 2 | Выбрать категорию «Замки» | На карте и в списке — только замки |
| 3 | Выбрать район «Несвижский» | Фильтрация по территории |
| 4 | Ввести в поиск «Мир» | Находится Мирский замок |
| 5 | «Определить моё местоположение» + радиус 50 км | Объекты рядом с вами |
| 6 | Кликнуть по объекту → «Построить маршрут» | На карте рисуется линия маршрута, показано расстояние и время |
| 7 | В карточке → «Похожие объекты» | Список объектов той же категории |
| 8 | В карточке → «Что рядом» | Объекты в радиусе от выбранного |

## 🔧 Возможные проблемы

### ❌ `Failed to fetch` / `Network Error` на фронте
**Причина:** Backend не запущен.  
**Решение:** Проверьте, что в первом терминале работает `uvicorn` и открывается http://127.0.0.1:8000/docs

### ❌ Ошибка `404` на `/api/attractions`
**Причина:** База не засеяна.  
**Решение:** В папке `backend` выполните `python -m app.seed`

### ❌ Карта серая / белая, маркеры не отображаются
**Причина:** Не загружен CSS Leaflet.  
**Решение:** Проверьте, что в `frontend/src/main.tsx` есть строка:
```ts
import "leaflet/dist/leaflet.css";
```

### ❌ Маршрут не строится
**Причина:** Демо-сервер OSRM (`router.project-osrm.org`) иногда отвечает медленно или недоступен.  
**Решение:** Подождите или попробуйте снова. Кнопка «Открыть в Яндекс Картах» остаётся рабочей.

### ❌ Геолокация не работает
**Причина:** Браузер блокирует геолокацию без HTTPS.  
**Решение:** Открывайте фронт строго по адресу `http://localhost:5173` (не по IP).

### ❌ `npm` / `node` не распознаются как команды
**Причина:** Node.js не установлен или не добавлен в PATH.  
**Решение:** Переустановите Node.js с сайта https://nodejs.org/ (версия LTS) и перезагрузите компьютер.

## 🔄 Повторный запуск (в следующий раз)

После первой настройки достаточно выполнять только это:

**Терминал 1 — Backend:**
```bash
cd backend
.\.venv\Scripts\Activate.ps1   # Windows
uvicorn app.main:app --reload
```

**Терминал 2 — Frontend:**
```bash
cd frontend
npm run dev
```

> 💡 Если перезагружали компьютер — сначала поднимите БД: `docker compose up -d` (в корне проекта).

## 📝 Примечания

- IDs объектов в базе могут меняться при повторном запуске `seed` — это нормально, фронтенд не хардкодит ID.
- Для чистой демо-версии по Минской области из seed убраны объекты других областей (например, Гольшаны).
- Демо-сервер OSRM бесплатный, но нестабильный — для продакшена нужен свой инстанс.
